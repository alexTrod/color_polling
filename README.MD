# Palette Ranker

Color palette ranking poll for app design.

## Usage

Team members can access the poll at: `https://alexTrod.github.io/color_polling/`

Results are automatically saved to `results.csv` in this repository.

## How It Works

1. Enter your name
2. Drag palettes to rank them (1st choice at top)
3. Click "Submit ranking"
4. Your ranking is saved to the CSV file

## Viewing Results

Download `results.csv` from the GitHub repo to analyze rankings in a spreadsheet or data analysis tool.
